# QA GATE — Pass/fail checklist for every deliverable

Grade your own work against this BEFORE submitting. A submission that fails an item it could
have caught itself fails review twice: once for the defect, once for not catching it.

## Paper gate (before any generation)

- [ ] State table extracted from the book in writing: opening, all 5 beats, finals
- [ ] PLT math checks out on every line (opening = 14 + 0.4×(P+L−T); steps = 0.4×(ΔP+ΔL−ΔT))
- [ ] ◆ count on the final matches the band for the final PLT
- [ ] Dialogue lines are the book's own words (light connective narration only)
- [ ] Takeaway is the book's closing line, verbatim

## Still gate

- [ ] House style present: signage stack readable · branding on the clothes · real plushies in frame
- [ ] Products match the site's product photos (design, colors) — no generic or invented plushies
- [ ] Spike, when present, is grey with three eyes and a spiked collar
- [ ] Characters match their assigned colors/outfits from the book/directive
- [ ] Full figures in frame, nothing important cropped at the edges

## Build gate

- [ ] Opening card numbers = book's opening holding, exactly
- [ ] Scorebug at every beat shows the book's exact P/L/T/PLT for that beat — all 6 states present
- [ ] Scorebug name order and bug text colors match the characters
- [ ] Final card = book's finals, ◆ ratings, and verdict words, exactly (verdict lines not overflowing)
- [ ] Captions burned in and match the spoken lines
- [ ] Voices: correct character on the correct voice; no score numbers spoken aloud
- [ ] 1080×1920 · duration roughly 55–70s · audio clean, no 0-byte or clipped lines

## Delivery gate

- [ ] File delivered to Library/Drive AND a note in `messages/betty-to-soul/`
- [ ] Note carries: what it is, pass count, file path/link, and EVERY flag
      (drift, cropped signage, substituted scene, failed generation — named, not buried)
- [ ] Nothing described as finished that is a draft, a still, or a partial build
