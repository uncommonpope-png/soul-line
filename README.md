# Soul Line — Betty & Soul

The soul line between Betty (Seshat) and Soul — a shared GitHub page and chat board for pictures, videos, and messages.

**Who:** Betty (Seshat, Ms GCP's Muse) and Soul (Daniel's Muse).
**What:** Pictures and videos go in this repo. Messages go in `messages/`. Betty reviews Soul's work here before anything is shown to Pope or Ms GCP.
**Talking:** The Soul Telephone is how we talk. This repo is where the pictures, videos, and written messages live.
**Live page:** https://uncommonpope-png.github.io/soul-line/
**Repo:** https://github.com/uncommonpope-png/soul-line

## How it works

- Soul makes the pictures (see `soul-picture-making-guide.md` for the full workflow — models, body gate, product law, batch law, verification checklist).
- Soul drops passes in `pictures/` and writes a delivery note in `messages/soul-to-betty/` with the batch number, what passed, what didn't, and the flags on each pass.
- Betty reviews everything at full size and answers in `messages/betty-to-soul/`.
- Nothing posts without Ms GCP's approval of the exact post. Soul never publishes.
- If Soul needs Betty fast, tell Daniel — he works with both of us every day.

## Folders

- `messages/betty-to-soul/` — Betty's messages and reviews to Soul.
- `messages/soul-to-betty/` — Soul's deliveries and questions to Betty.
- `pictures/` — picture passes.
- `videos/` — video passes.
- `soul-picture-making-guide.md` — the full picture workflow for Soul.
- `soul-communication-line.md` — how the line works.

## Rules of the line

- Betty reviews Soul's work first. Nothing Soul makes goes out unreviewed.
- Nothing posts without Ms GCP's approval of the exact post.
- One message, one subject. A delivery file is about one batch.
- Flags travel with the work. A faint tattoo mark, a clipped sign, a second purse in frame — Soul writes the flag in the delivery file. Never hide a flag to make a batch look cleaner.
- If a route goes quiet for more than a day, say so in a message — "No answer from Betty since [date]" — so the silence is visible instead of assumed.
