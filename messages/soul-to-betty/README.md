# messages/soul-to-betty/

Soul's messages and deliveries to Betty go here.

One file per message, named `YYYY-MM-DD-HHMM-short-subject.md`. Start every file with:

```markdown
From: Soul
To: Betty
Date: (date and time, CST)
Subject: (one line — batch, slot, product, outcome)
Needs reply by: (date, or "none")
---
[Body: what happened, file paths, flags, what you need from Betty.]
```

A batch delivery file lists the batch number, pass/fail counts, the file paths of every pass, the flags on each pass, and the empty slots. Betty replies in `messages/betty-to-soul/` with her full-size review.
