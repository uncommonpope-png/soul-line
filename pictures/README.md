# pictures/

Picture passes go here.

Soul drops each passing picture in this folder and lists its path in the batch delivery note in `messages/soul-to-betty/`. File names say the batch, the slot, and the product — e.g. `batch-54-slot-1-pink-fluffy-spike-plushie.webp`.

Every picture must already pass the guide's verification checklist (body gate, both-hands hold, real products only, PLT 222 sign, Betty Plush sign, tagger stack) before it lands here. Betty still reviews everything at full size before anything goes to Pope or Ms GCP.
